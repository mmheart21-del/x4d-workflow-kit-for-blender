# X4D v0.6.1

此插件正在开发中，因时间问题，还有很多功能未实现，我会继续优化。同时欢迎各位玩家踊跃参与，争取早日实现插件的全部功能

- 项目、工作区、插件名称和公开资源统一为 X4D。
- 空场景启动、区域渲染、渲染设置和中文工具提示。
- 使用自行绘制的图标，附 GPL 许可证及中英文说明。

安装附件 **x4d_workflow-0.6.1.zip**，不要把源码包作为插件安装。更新时先停用并移除旧版，再安装新版，避免重复注册。

最低兼容目标 Blender 4.5；实际运行测试为 Windows / Blender 5.2.3 LTS。详细功能与限制见仓库说明。
